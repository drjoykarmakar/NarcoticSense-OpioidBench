# v0.5.0 reporting pipeline (development)

This pipeline is **code for a future v0.5.0 milestone**, not a claim that v0.5.0
has been released or that new experimental metrics have been validated.

## Usage

First generate frozen baseline outputs locally with `opioidbench benchmark baselines`
for each protocol. Then run:

```bash
opioidbench benchmark report \
  --run compound=results/private/pilot_benchmark/compound_cv5/baselines \
  --run scaffold=results/private/pilot_benchmark/scaffold_cv5/baselines \
  --run analogue=results/private/pilot_benchmark/analogue_cv5/baselines \
  --output results/private/public_report_review
```

Input for each protocol: `summary.json` and `fold_metrics.csv` generated by
`opioidbench benchmark baselines`. **No row-level predictions are read.**

The command validates expected model/fold completeness, cohort counts, confusion
matrix counts, numeric ranges, and fold mean/population-standard-deviation
consistency against `summary.json`. It then emits:

- `pilot_metrics.json`: explicit allowlisted aggregate metrics and pooled
  out-of-fold confusion counts;
- `pilot_metrics.csv`: flat aggregate table for manuscript preparation.

Output contains no source spectra, prediction rows, sample/compound identifiers,
source filenames, or input directory paths. The output should still undergo
human disclosure review before publication.

**Important:** The existing baseline exporter can emit NaN for undefined AUROC
or average precision on a one-class test fold. This reporter deliberately fails
closed on non-finite values. Only complete two-class fold runs with finite
metrics are supported.

The repository's `.gitignore` excludes generated files under `results/`.
Do not force-add any private inputs or output directory. No automatic publication
or external data upload is performed.

## Validation and scientific interpretation

- Means and standard deviations are unweighted across folds.
- Confusion counts are summed across held-out folds; pooled accuracy and F1
  derived from these counts need not equal the mean fold metrics.
- Reported metrics are internal cross-validation only, not ENFSI external
  classification performance or evidence of forensic deployment readiness.
- This reporter validates **consistency of aggregate metrics**, not chemical
  group assignments or spectral overlap. Existing split-generation leakage
  audits must be run and reviewed independently.
- Random, compound, scaffold, and analogue protocols may use different cohorts;
  compare like-for-like cohorts before attributing metric differences solely
  to protocol difficulty.

Run synthetic tests with `pytest tests/test_reporting.py`.
